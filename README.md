# pswd — 本地命令行密码生成与记录管理工具

## 一、项目解决什么问题

在多个应用 / 多个账号下需要留存密码时，手工记录容易遗漏、事后难以核对。
本工具是一个纯本地运行的控制台小程序：根据「应用标识 + 当前时间戳」按固定
规则生成密码，并把生成记录（应用标识、密码、可选账号标识）保存到本地
`password.json` 文件中，方便事后查看和检索。所有数据只保存在本机，不进行
任何网络传输。

## 二、主要功能

1. **生成密码**：交互式输入应用标识（必填；留空时提示并取消本次生成，不创建
   记录）和可选的账号标识（手机号 / 邮箱，仅用于区分账号，不参与密码拼接），
   按固定规则生成密码并在控制台显示。
2. **记录保存**：新记录以 JSON 数组形式追加写入程序（或脚本）同目录下的
   `password.json`；文件损坏、为空或解析失败时自动按空列表处理；旧数据若是
   单个对象也会自动兼容为数组。
3. **查看全部记录**：列出本地保存的全部密码记录。
4. **关键字查找**：按关键字在应用标识、账号标识中做模糊匹配，列出匹配记录。
5. **重复提示**：生成时若发现已存在相同应用标识与账号的记录，给出提示（仍会
   追加保存）。

### 密码生成规则

最终密码由三部分拼接而成：

```
密码 = 应用标识 + "@" + 时间戳尾部
```

时间戳尾部的生成步骤：

1. 当前时间格式化为 `YYYYMMDDHHMMSS`（例如 `20260607234559`）；
2. 转为整数后再转为十六进制字符串，去掉 `0x` 前缀；
3. 对十六进制字符串中的每个字符做 ASCII 码 +2 处理，得到尾部。

> 示例：时间 `2026-06-07 23:45:59` → 时间串 `20260607234559` →
> 十六进制 `126d4a4c11ff` → 逐字符 ASCII +2 → 尾部 `348f6c6e33hh`，
> 应用标识为 `google` 时密码为 `google@348f6c6e33hh`。

## 三、安装使用方法

### 项目结构

```
pswd/
├── pswd.py            # Python 源码
├── pswd.spec          # PyInstaller 打包配置
├── dist/
│   └── pswd.exe       # 编译好的 Windows 64 位可执行程序
└── build/             # 打包中间产物（可由源码重新生成）
```

### 方式 A：直接使用编译好的程序（推荐）

- 运行环境：**Windows 64 位（AMD64）**，无需安装 Python。
- 进入 `dist` 目录，双击 `pswd.exe`，或在终端中运行：

```powershell
dist\pswd.exe
```

- 首次运行会在 `pswd.exe` 所在目录自动生成 `password.json` 记录文件。

### 方式 B：以源码方式运行

- 需要 Python 3.10 及以上版本（开发环境为 Python 3.14），无第三方依赖。

```powershell
python pswd.py
```

### 从源码重新编译 win64 可执行程序

```powershell
pip install pyinstaller
pyinstaller --onefile --console --clean --noconfirm --name pswd pswd.py
```

编译完成后，可执行程序位于 `dist\pswd.exe`。

### 菜单操作

启动后进入主菜单，按提示输入数字选择操作：

| 选项 | 功能 |
| ---- | ---- |
| 1 | 生成新密码 |
| 2 | 查看全部记录 |
| 3 | 按关键字查找记录 |
| 4 | 退出 |

## 四、输入输出示例

> 以下示例中的密码尾部对应生成时间 `2026-06-07 23:45:59`；实际使用时尾部
> 会随生成时间变化。

### 示例 1：生成带账号标识的密码

控制台交互（输入内容在提示词之后）：

```text
===== 密码生成与记录管理工具 =====
1. 生成新密码
2. 查看全部记录
3. 按关键字查找记录
4. 退出

请选择操作（1-4）: 1
请输入应用标识（例如 google、facebook）: google
请输入手机号或邮箱（用于区分账号，若不需则直接回车）: user@example.com
应用标识：google，账号：user@example.com，生成的密码为：google@348f6c6e33hh
已保存记录到 ...\password.json
```

### 示例 2：应用标识留空，取消生成

```text
请选择操作（1-4）: 1
请输入应用标识（例如 google、facebook）:
应用标识不能为空，已取消生成。
```

此时不会询问账号标识，也不会生成密码或写入 `password.json`，直接回到主菜单。

### 示例 3：查看全部记录

```text
请选择操作（1-4）: 2
共 2 条记录：
[1] 应用：google  账号：user@example.com  密码：google@348f6c6e33hh
[2] 应用：github  账号：—  密码：github@348f6c6e33hh
```

### 示例 4：按关键字查找记录

```text
请选择操作（1-4）: 3
请输入要查找的应用标识或账号关键字: google
找到 1 条匹配记录：
[1] 应用：google  账号：user@example.com  密码：google@348f6c6e33hh
```

### 输出文件 `password.json`

记录文件为 JSON 数组，UTF-8 编码，每条记录包含 `app`（应用标识）、
`password`（生成的密码）；填写了账号标识时额外包含 `id` 字段：

```json
[
    {
        "app": "google",
        "password": "google@348f6c6e33hh",
        "id": "user@example.com"
    },
    {
        "app": "github",
        "password": "github@348f6c6e33hh"
    }
]
```

## 五、注意事项

- 密码尾部由**秒级**时间戳生成，同一秒内多次生成会得到相同的密码。
- 记录仅保存在本机 `password.json`，不涉及网络传输，请自行妥善保管该文件。
- 账号标识（手机号 / 邮箱）仅用于记录和区分账号，不参与密码拼接。
- 本工具为控制台交互程序，所有操作通过主菜单数字选项完成。
